## 项目制作过程

这是本人的第一个技术项目。期间最大的挑战是 GitHub 工作流的使用：多仓库管理混乱、网络不稳定导致 push/pull 频繁 conflict、不同 AI 工具（元宝 vs DeepSeek-V4-Pro）的效果差异。在多次终端操作后，改用 VS Code 内置 Agent 插件 DeepSeek 将元宝的 100 多次无效修改回退到干净状态，重新分步提交，修复了分支和个人网站部署。后续熟练后效率明显提高。

项目中 AI 辅助编程的核心经验：AI 在纯代码逻辑（算法、数据结构、功能实现）方面表现稳定；在涉及浏览器底层行为（Canvas 图片渲染、iOS 兼容性）时容易出错。亲自运行代码是唯一的查证标准。

电路部分以学习知识，输出知识为主。不过运用得还不算熟练www

### 3.2 查证：AI 给出但经运行验证为错误的信息

以下由 AI (DeepSeek-V4-Pro) 在对话中提出，经亲自运行确认不可行：

| 编号 | AI 方案 | 实际结果 | 处理 |

### 3.5 AI 核心算法机制分析（防纯粘贴说明）

- **BFS 寻路**：广度优先搜索，逐层扩散寻找最短路径，被阻挡时停止该方向扩散，避免探索死路
- **追尾保命**：蛇身围住食物形成环路时自动追尾，利用蛇尾持续移动打破死胡同。实测发现仍可能陷入环形死锁（AI 首局停在 199 分无法吃到下一食物）
- **饥饿模式**：棋盘 400 格，约 300 步可遍历大部分区域。超过 350 步未吃到食物时，判定为环形死锁，启动宽松检查强制寻路，风险增大但可打破僵局

### 4.A 进阶挑战一 · 任务①：RC 滤波电路仿真验证

#### 4.A.1 电路拓扑

一阶 RC 低通滤波器：电阻 R 串联，电容 C 并联到地，输出从电容两端取出。

```
       R = 1 kΩ
  vi ──/\/\/───┬─── vo
               │
              ─── C = 1 μF
              ───
               │
              GND
```

**选型依据**：R = 1 kΩ、C = 1 μF → τ = RC = 1 ms，fc = 159.15 Hz，音频范围内便于观测。

#### 4.A.2 理论推导

**传递函数**（阻抗分压）：

$$H(j\omega)=\frac{Z_C}{Z_R+Z_C}=\frac{1/(j\omega C)}{R+1/(j\omega C)}=\frac{1}{1+j\omega RC}$$

令 ωc = 1/RC：

$$H(j\omega)=\frac{1}{1+j(\omega/\omega_c)}$$

**截止频率**：

$$f_c=\frac{1}{2\pi RC}=\frac{1}{2\pi\times1000\times10^{-6}}\approx159.15\ \text{Hz}$$

**幅频特性**（增益）：

$$|H(f)|=\frac{1}{\sqrt{1+(f/f_c)^2}}$$

- f ≪ fc：|H| ≈ 1（通带，信号几乎全通过）
- f = fc：|H| = 1/√2 ≈ 0.707（−3 dB 截止点）
- f ≫ fc：|H| ≈ fc/f → 0（阻带，每 10 倍频衰减 20 dB）

**相频特性**：φ = −arctan(f/fc)，fc 处 φ = −45°，高频极限 −90°。

**阶跃响应**（时域）：

$$v_o(t)=1-e^{-t/\tau},\quad \tau=RC=1\ \text{ms}$$

| 时间 | vo | 说明 |
|------|-----|------|
| t = 0 | 0 V | 初始状态 |
| t = τ = 1 ms | 0.632 V | 充至 63.2% |
| t = 3τ = 3 ms | 0.950 V | 充至 95.0% |
| t = 5τ = 5 ms | 0.993 V | 工程稳态 |

#### 4.A.3 仿真

PySpice + Ngspice 47，三类仿真：

| 类型 | 参数 | 目的 |
|------|------|------|
| AC 频率扫描 | 10 Hz → 100 kHz，对数 200 点 | 幅频/相频特性 |
| 阶跃响应 | 0 → 8 ms | RC 充放电曲线 |
| 正弦瞬态 | 0.1fc / fc / 10fc | 通带/截止/阻带波形 |

#### 4.A.4 手算 vs 仿真对比

| 项目 | 手算值 | 仿真值 | 误差 |
|------|--------|--------|------|
| 截止频率 fc | 159.15 Hz | 158.49 Hz | — |
| 增益 @ fc | 0.7071 | 0.7086 | 0.21% |
| 相位 @ fc | −45.00° | −44.88° | 0.12° |
| vo(τ) @ 1ms | 0.6321 V | 0.6329 V | 0.77 mV |
| vo(3τ) @ 3ms | 0.9502 V | 0.9503 V | 0.11 mV |
| 通带增益 16 Hz | 0.9950 | 0.9949 | 0.01% |
| 阻带增益 1592 Hz | 0.0995 | 0.1028 | 3.27% |

#### 4.A.5 结论

手算与仿真高度一致：fc 处增益误差 0.21%，阶跃响应各点误差在毫伏级。验证了阻抗分压法推导传递函数的正确性及 τ = RC 的物理意义。10fc 处 3.27% 误差源于低幅值采样精度限制，不影响结论。

```
    │     n1        │
    ├───/\/\/───┐   │
    │    R1=5Ω  │   │

    │    ┌─────┐    │
    │    │VCCS ├────┤  GM = 0.1 S
    │    └──┬──┘    │  I = GM × V(R1)，方向 a → GND
    ├───/\/\/───────┘
             R2=10Ω
              │
             GND
```

- 电压源 Us = 10V
- R1 = 5Ω（串联），R2 = 10Ω（并联）
- VCCS：跨导 GM = 0.1 S，电流 I = 0.1 × V(R1)

### 4.B.3 手算推导

#### ① 开路电压 Uoc（RL → ∞）

KCL @ a：

$$\frac{V(a) - 10}{5} + \frac{V(a)}{10} + 0.1(10 - V(a)) = 0$$

$$\boxed{U_{oc} = 5.000\ \text{V}}$$

#### ② 短路电流 Isc（RL → 0）

V(a) = 0，R2 被短路：

$$I_{R1} = \frac{10}{5} = 2\ \text{A}, \quad I_{VCCS} = 0.1 \times 10 = 1\ \text{A}$$

$$\boxed{I_{sc} = 2 - 1 = 1.000\ \text{A}}$$

#### ③ 等效电阻 Req

**方法 A** · 开路短路法：

$$R_{eq} = \frac{U_{oc}}{I_{sc}} = \frac{5.000}{1.000} = \boxed{5.000\ \Omega}$$

**方法 B** · 加压求流法（含受控源的正统做法，独立源置零，端口加测试电压）：

$$I = \frac{U}{10} + \frac{U}{5} - 0.1U = 0.2U \quad\Rightarrow\quad R_{eq} = \frac{U}{I} = \boxed{5.000\ \Omega}$$

**方法 C** · 串并联法（错误示范）：

$$R_1 \parallel R_2 = \frac{5 \times 10}{5 + 10} = 3.33\ \Omega \quad\leftarrow \text{受控源存在时失效}$$

### 4.C 进阶挑战一 · 任务③：NMOS 共源级放大电路

#### 4.C.1 电路拓扑

NMOS 共源级放大电路：栅极由 Rg1/Rg2 分压偏置，输入 vi 经 Cb1 耦合至栅极，漏极经 Rd 接 VDD，源极接地，输出 vo 从漏极取出。

```
                  VDD = 5V
                    │
                   ┌┴┐
                   │ │ Rd = 2 kΩ
                   │ │
                   └┬┘
                    ├──────── vo（输出）
                    │
        vi ── Cb1 ──┤ 栅极 g ──┬── Rg1 = 60kΩ ── VDD
                    │          │
                    │  M1      ├── Rg2 = 40kΩ ── GND
                    │ (NMOS)   │
                    │          │
                    │ 源极 s ──┴── GND
```

**参数**：VDD=5V, Rg1=60kΩ, Rg2=40kΩ, Rd=2kΩ, K=0.8mA/V², Vth=1V, λ=0.02/V, Cb1=10μF（自选）。

**K 约定声明**：本文采用写法 A，即 Id = K·(Vgs−Vth)²。对应 ngspice 设置 KP·(W/L)=2K=1.6mA/V²（KP=160μA/V², W/L=10/1, LEVEL=1）。

#### 4.C.2 理论推导（七步法）

**① 栅极分压**（电阻串联分压，MOS 栅极绝缘不取电流）：

$$V_g = V_{DD} \cdot \frac{R_{g2}}{R_{g1}+R_{g2}} = 5 \times \frac{40}{100} = 2.000\ \text{V}$$

**② 过驱动电压**：Vov = Vg − Vth = 2 − 1 = 1.000 V

**③ 漏极电流**（饱和区方程，写法 A）：

$$I_d = K \cdot V_{ov}^2 = 0.8 \times 1^2 = 0.800\ \text{mA}$$

**④ 漏极电压**（KVL + 欧姆定律）：

$$V_d = V_{DD} - I_d \cdot R_d = 5 - 0.8 \times 2 = 3.400\ \text{V}$$

**⑤ 饱和区验证**：Vds = Vd = 3.400 V ≥ Vov = 1.000 V ✅

**⑥ 跨导**（写法 A 下 gm = 2K·Vov）：

$$g_m = 2K \cdot V_{ov} = 2 \times 0.8 \times 1 = 1.600\ \text{mS}$$

**⑦ 输出电阻**（沟道长度调制）：

$$r_o = \frac{1}{\lambda \cdot I_d} = \frac{1}{0.02 \times 0.8\times10^{-3}} = 62.5\ \text{k}\Omega$$

**⑧ 电压增益**（小信号模型，共源级反相）：

$$R_{out} = R_d \parallel r_o = \frac{2 \times 62.5}{2 + 62.5} = 1.938\ \text{k}\Omega$$

$$A_v = -g_m \cdot R_{out} = -1.600 \times 1.938 = -3.10$$

负号表示反相（共源级标志），输入升高 → Id 增大 → Rd 压降增大 → 漏极电压降低。

**λ 修正**（含沟道长度调制）：

| 参数 | 忽略 λ | 含 λ | 变化 |
|------|--------|------|------|
| Id | 0.800 mA | 0.854 mA | +6.8% |
| Vd | 3.400 V | 3.291 V | −0.109 V |
| ro | 62.5 kΩ | 58.5 kΩ | −6.4% |
| Av | −3.10 | −3.09 | 0.2% |

⭐ **λ 对 Id 影响 6.8%，对 Av 影响仅 0.2%**，因为 gm 不变而 ro 变化对 Av 的贡献极小（Rd=2kΩ 远小于 ro）。

#### 4.C.3 仿真

PySpice + Ngspice 47，共 5 项分析：

| 分析类型 | 参数 | 目的 |
|----------|------|------|
| .op | Vgs=2V, Vds≈3.29V | Q 点提取 |
| .dc Vgs 0→3V | — | 转移特性 Id−Vgs |
| .dc Vds 0→5V（Vgs=1.5/2.0/2.5V） | — | 输出特性，观 λ 效应 |
| .ac 0.1Hz→10MHz | 对数 200 点 | 中频增益 |
| .tran 0→0.3ms | vi=10mV@10kHz | 瞬态放大 + 反相 |

**头号坑 · KP 与 K 的 2 倍关系**：

| | 手算 | Ngspice |
|--|------|---------|
| 电流方程 | Id = K·Vov² | Id = ½·KP·(W/L)·Vov²·(1+λ·Vds) |
| 参数 | K = 0.8 mA/V² | KP = 160 μA/V², W/L = 10 |

令 KP·(W/L) = 2K = 1.6 mA/V²，方使仿真 Id 与手算一致。若误设 KP·(W/L) = K = 0.8 mA/V²，Id 将偏小一半（0.4 mA）。

#### 4.C.4 手算 vs 仿真对比

| 项目 | 手算（推荐） | 手算（含λ） | 仿真 | 误差 |
|------|------------|-----------|------|------|
| 栅极电压 Vg | 2.000 V | 2.000 V | 2.000 V | 0% |
| 过驱动电压 Vov | 1.000 V | 1.000 V | 1.000 V | 0% |
| 漏极电流 Id | 0.800 mA | 0.854 mA | 0.853 mA | 0.2% |
| 漏极电压 Vd | 3.400 V | 3.291 V | 3.295 V | 0.1% |
| 跨导 gm | 1.600 mS | 1.600 mS | 1.653 mS | 3.3% |
| 输出电阻 ro | 62.5 kΩ | 58.5 kΩ | 58.6 kΩ | 0.2% |
| 电压增益 Av | **−3.10** | −3.09 | −3.31 | 6.4% |
| 工作区 | 饱和 ✅ | 饱和 ✅ | 饱和 ✅ | 一致 |

#### 4.C.5 误差分析

gm 仿真值（1.653 mS）与手算（1.600 mS）差 3.3%，源于 ngspice LEVEL=1 模型中 gm = KP·(W/L)·Vov·(1+λ·Vds) ≈ 1.71 mS（含 λ 因子），而手算 gm = 2K·Vov = 1.6 mS 忽略了此修正。AC 中频增益 −3.31 与手算 −3.10 差 6.4%，同样由 gm 的 λ 因子导致。Id、Vd、ro 的仿真值均与含 λ 手算高度一致（误差 < 0.2%），验证了模型设置的准确性。

#### 4.C.6 结论

NMOS 共源级放大电路工作在饱和区（Vds=3.29V > Vov=1.00V），中频电压增益约 −3.10（手算）至 −3.31（仿真），输入输出反相。KP·(W/L) 必须设为 2K=1.6mA/V² 才能与手算 Id 吻合，此为头号坑。λ=0.02/V 对 Id 影响 6.8%，但对 Av 影响仅 0.2%（因 Rd≪ro）。仿真结果与手算高度一致，验证了静态工作点计算和小信号增益公式的正确性。
